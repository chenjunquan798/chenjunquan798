I build with language models — mostly the unglamorous half: grounding answers in real corpora, keeping tool-using agents on a leash, and building the evaluation that decides whether any of it ships.

<sub>我用语言模型做产品，做的多是“不性感”的那一半：让答案落回真实语料、让调用工具的智能体始终有边界，以及决定它到底能不能上线的那套评测。</sub>

---

## Now · 现在

**Currently** — turning this profile into a public lab for applied LLM work: retrieval pipelines, agent tooling, and eval harnesses that hold up outside a demo.

<sub>当前：把这个主页做成 LLM 应用的公开实验场——检索管线、智能体工具链，以及能扛住 demo 之外真实场景的评测框架。</sub>

**Open to** — collaboration on retrieval, evaluation, and developer tooling. If you are working on the same problems, open an issue or start a discussion.

<sub>乐于合作的方向：检索、评测、开发者工具。如果在做同类问题，欢迎开 issue 或 discussion。</sub>

## Focus · 关注方向

| Domain | In practice |
| :--- | :--- |
| **Retrieval & grounding** | Hybrid search, reranking, and citation-first answers over private corpora.<br><sub>混合检索、重排序；基于私有语料的答案必须带出处。</sub> |
| **Agents & tool use** | Bounded tool loops with tracing, retries, and hard cost ceilings.<br><sub>有边界的工具调用循环：可追踪、可重试、成本有硬上限。</sub> |
| **Evaluation** | Golden sets, judge models with human spot checks, regression gates in CI.<br><sub>金标集、模型评审加人工抽检、CI 里的回归门禁。</sub> |
